  • 能力靠 prompt 描述，可被「幻觉」出不存在的操作

HELIOS · Agents as Operators

agents 是操作者

  • 设备注册为 skill：typed primitives + 安全等级 + 前置/效果契约
  • agent 只能调用已声明 primitive —— 无法幻觉出不存在的操作
  • 智能在编排与优化层，与模型解耦
  • Mock LLM，campaign loop 依然闭合

The Cleanest Test 08

Mock out the LLM, and the entire campaign loop still closes.

因为智能活在编排与优化层，而不是 prompt 胶水里。 契约、租约、技能、事件总线、恢复 —— 全部为 agent 而设计。
